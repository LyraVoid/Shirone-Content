# 常见问题与排错手册

本篇文档汇总了在内容分离架构使用过程中可能遇到的常见疑问与排错方法。

---

## 1. 推送内容后，网站没有更新？

请按照以下顺序逐步排查：

### 排查 A：检查 GitHub Actions 运行记录
1. 打开你的**内容仓库**的 **Actions** 标签页；
2. 查看最新一次的 `Trigger Theme Build` 是否成功打钩（绿色）；
3. 如果显示红色失败，点击进入查看错误日志：
   - 如果提示 `Resource not accessible by personal access token`，说明你的 `DISPATCH_TOKEN` 没有授予主题代码仓的 **Contents: Read and write** 权限，请重新生成并更新密钥；
   - 如果提示校验未通过，说明你的某个 YAML 文件中存在格式或类型错误。

### 排查 B：检查文章是否被标记为了草稿
检查文章顶部的 Frontmatter 中是否写了：
```yaml
draft: true
```
当 `draft: true` 时，文章属于草稿状态，在生产环境构建时会被自动过滤隐藏。将其修改为 `draft: false` 即可正常展示。

### 排查 C：检查文章发布日期格式
发布日期必须遵循严格的 ISO 日期格式，例如：
- 正确：`published: 2026-08-27`
- 错误：`published: 2026/8/27` 或 `published: 2026.08.27`

## 2. 修改 YAML 文件后提示类型检查报错？

Shirone 拥有严格的类型检查系统。如果终端或 Actions 输出类似：
```text
Type '{ titel: string }' is not assignable to type 'SiteConfigOverride'
Did you mean "title"?
```
- 这说明你在 YAML 中写了一个主题不认识的属性名称；
- 请仔细核对对应配置文档，修改为正确的拼写即可。

---

## 3. 外链图片无法加载或出现 403 拒绝访问？

如果使用的是第三方图床（如 B 站图床），通常是因为图床启用了 Referer 防盗链机制。

### 解决方法：
在 `config/site.yaml` 中添加该图床的域名白名单：
```yaml
imageOptimization:
  noReferrerDomains:
    - "*.hdslb.com"
    - "*.bilibili.com"
```
主题会自动为该域名的图片添加防盗链绕过属性。

---

## 4. 修改 `docs/` 教程文档会消耗构建额度吗？

**完全不会。**
`docs/` 目录以及根目录的 `README.md` 已在触发流水线和同步脚本中进行了双重排除过滤。向 `docs/` 提交文档修改不会向代码仓派发构建请求，也不会触发任何构建计费。
