# 托管平台部署钩子模式

如果你习惯直接使用 Cloudflare Pages、Vercel、腾讯云 EdgeOne 或 Netlify 等云平台托管你的主题代码仓库，并且平台的云端构建机支持在构建阶段拉取外部私有内容仓，你可以使用**部署钩子直连模式**。

在这种模式下，内容仓库推送到 `main` 分支后，工作流会自动向你配置的平台部署钩子发送网络请求，通知平台立即启动构建。

---

## 1. Cloudflare Pages 配置步骤

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，点击进入你的 Pages 项目；
2. 点击顶部导航的 **Settings**（设置），选择 **Builds & deployments**；
3. 向下滚动找到 **Deploy hooks** 区域，点击 **Add deploy hook**；
4. 设置一个名称（如 `content-update`），分支选择 `main`，点击 **Save**；
5. 复制生成的 Webhook 地址；
6. 打开你的**内容仓库** -> **Settings** -> **Secrets and variables** -> **Actions**，点击 **New repository secret**；
7. 名称填写 `CLOUDFLARE_DEPLOY_HOOK`，值填入复制的地址并保存。

---

## 2. Vercel 配置步骤

1. 登录 [Vercel 控制台](https://vercel.com/)，点击进入你的项目；
2. 进入 **Settings** -> **Git**；
3. 向下滚动找到 **Deploy Hooks**，输入名称并指定分支为 `main`；
4. 点击 **Create Hook**，复制生成的 Webhook 地址；
5. 打开你的**内容仓库** -> **Settings** -> **Secrets and variables** -> **Actions**；
6. 添加名称为 `VERCEL_DEPLOY_HOOK` 的密钥，值为该 Webhook 地址。

---

## 3. 腾讯云 EdgeOne Pages 配置步骤

1. 登录 [腾讯云 EdgeOne 控制台](https://console.cloud.tencent.com/edgeone/pages)，进入你的 Pages 应用；
2. 进入应用详情页，点击左侧菜单的 **触发器**；
3. 点击 **新建触发器**，类型选择 **部署钩子**，分支选择 `main`；
4. 复制生成的部署钩子 URL；
5. 打开你的**内容仓库** -> **Settings** -> **Secrets and variables** -> **Actions**；
6. 添加名称为 `EDGEONE_DEPLOY_HOOK` 的密钥，值为该 URL。

---

## 4. Netlify 配置步骤

1. 登录 [Netlify 控制台](https://app.netlify.com/)，进入你的网站项目；
2. 进入 **Site configuration** -> **Build & deploy** -> **Continuous deployment**；
3. 找到 **Build hooks**，点击 **Add build hook**，指定分支为 `main`；
4. 复制生成的 Webhook 地址；
5. 打开你的**内容仓库** -> **Settings** -> **Secrets and variables** -> **Actions**；
6. 添加名称为 `NETLIFY_DEPLOY_HOOK` 的密钥，值为该地址。

---

## 平台构建机环境变量配置

当使用平台原生构建拉取私有内容仓库时，需要在托管平台的**环境变量设置**中配置以下关键参数：

| 环境变量名 | 推荐填入值 | 作用说明 |
| --- | --- | --- |
| `NODE_VERSION` | `22` | 指定 Node 运行版本，确保支持最新语法 |
| `GIT_TERMINAL_PROMPT` | `0` | 防止 Git 在后台执行时发生交互式等待 |
| `CONTENT_REPO_URL` | `https://x-access-token:你的GitHub令牌@github.com/用户名/内容仓名.git` | 带私有访问权限的内容仓库克隆地址 |
| `BILI_SESSDATA` | `你的凭证` | 可选，用于私密追番数据拉取 |
