# Shirone 内容分离使用教程

本文档库为 Shirone 博客主题的内容分离使用指南，指导博主完成独立内容仓库的初始化、全站参数配置、文章与数据实体管理，以及自动化构建流水线的配置。

> 说明：`docs/` 目录已被同步脚本与触发工作流完全排除。在本目录中编写或修改教程文档不会触发生产环境的重新构建，也不会被物化至代码仓库。

---
