# 配置覆盖核心原理

在 Shirone 主题中，你无需直接修改主题源码中的 TypeScript 配置文件，所有个性化设置均在内容仓库的 `config/` 目录下的各个 YAML 文件中完成。

---

## 三大黄金法则

### 法则一：按需覆盖，只写想改的

在内容仓的 YAML 文件中，**千万不要把主题的所有默认配置全部抄一遍**。你只需要写下你想修改的项。

例如，如果你只想修改博客标题和主题色相，你的 `config/site.yaml` 只需要写 4 行：

```yaml
title: "黎明的小站"
themeColor:
  hue: 262
```

**为什么这样做最好？**
因为未显式声明的选项会自动沿用主题内置的默认值。当主题未来升级并新增了新的视觉特效或排版功能时，你的博客会自动跟进新特性，绝不会因为旧配置被“冻结”而无法生效。

---

### 法则二：字典深度合并，列表整体替换

在 YAML 语法中，数据主要分为两种结构，它们的合并逻辑完全不同：

#### 1. 字典对象（键值对）：逐层向下深度合并
对于字典结构（如 `themeColor`、`displaySettings`、`banner.dim` 等），系统会智能比对子属性。你只修改其中一个子属性，其他兄弟属性依然保留默认值。

#### 2. 列表数组（以 `- ` 开头的条目）：整体替换
对于列表结构（如导航栏链接 `nav-bar.yaml`、侧边栏组件排布 `sidebar.yaml`、字体清单 `font.yaml`、LLMs 核心页面 `llms.yaml`），系统的语义是**“这份列表就是我要的全部内容”**。
- 如果你只想在导航栏中删掉一个菜单或新增一个外链，你必须将整份导航栏清单完整写出来；
- 这样做能确保列表的顺序、删除与新增完全按照你的意图呈现，避免产生歧义。

---

### 法则三：编译期强类型拦截，拼错立即报错

许多静态博客在 YAML 字段拼写错误时会静默忽略，导致博主花费大量时间排查为什么设置不生效。

Shirone 具备严格的强类型编译器：
- 如果你把 `title` 误拼成了 `titel`；
- 如果你把枚举值 `single` 误填成了 `one`；
- 如果你把数字类型的参数填成了字符串；

在执行同步或构建时，系统会立即在终端报错，并精准指出错误所在的文件、行号以及修正建议（例如给出 `Did you mean "title"?`），确保错误在上线前被彻底拦截。

## 20 个配置文件对应关系表

所有配置文件均存放在内容仓库的 `config/` 目录下：

| 配置文件路径 | 负责的功能领域 |
| :--- | :--- |
| `config/site.yaml` | 站点基本信息、横幅壁纸、多图轮播、动态取色、背景纹理 |
| `config/profile.yaml` | 博主头像、名称、个性签名、社交平台链接 |
| `config/nav-bar.yaml` | 顶部导航栏条目、下拉子菜单与自定义外链 |
| `config/sidebar.yaml` | 侧边栏单栏或双栏模式、侧栏组件展示与粘性吸顶 |
| `config/anime.yaml` | 追番追剧页面主数据源与同步策略 |
| `config/music.yaml` | 侧栏音乐播放器四种模式与歌单配置 |
| `config/comment.yaml` | 评论系统提供商与连接参数 |
| `config/font.yaml` | 全站中文字体、西文字体与等宽代码字体 |
| `config/post-list.yaml` | 文章列表分页大小与排版模式（列表或网格） |
| `config/article.yaml` | 文章阅读时长、长期未更新提醒与底部推荐阅读 |
| `config/devices.yaml` | 个人数码设备展示页分类与筛选规则 |
| `config/projects.yaml` | 开源项目展示页分类与筛选规则 |
| `config/skills.yaml` | 技能图谱页分类与熟练度规则 |
| `config/timeline.yaml` | 大事记时间线分类与排序方向 |
| `config/fab.yaml` | 右下角悬浮操作按钮清单与对齐边距 |
| `config/image-bloom.yaml` | 图片加载色彩辉光防抖占位动画参数 |
| `config/expressive-code.yaml` | 文章代码高亮浅色与深色主题 |
| `config/license.yaml` | 文章底部版权协议声明 |
| `config/announcement.yaml` | 首页顶部公告栏文案与链接 |
| `config/llms.yaml` | 大语言模型与 AI 检索端点（/llms.txt 与 /llms-full.txt）、排除标签与核心引导页 |
| `config/footer.yaml` & `config/footer.html` | 页脚自定义 HTML 片段注入 |
