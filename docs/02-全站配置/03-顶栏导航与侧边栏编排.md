# 顶栏导航与侧边栏编排

## 一、顶部导航栏配置：`config/nav-bar.yaml`

顶部导航栏决定了博客顶栏与移动端侧边抽屉的菜单结构。由于采用整体替换模式，你的配置文件需要列出全部你希望展示的导航条目。

### 1. 基础预设项与自定义链接

每个导航项支持三种写法：

#### 写法 A：使用主题内置预设（推荐）
内置预设会自动匹配当前站点的语言翻译与标准圆角图标：
```yaml
links:
  - preset: Home        # 主页
  - preset: Archive     # 归档
  - preset: Friends     # 友链
```
常用预设名称清单：
- `Home`：主页
- `Archive`：归档
- `Friends`：友链
- `Moments`：说说
- `Anime`：追番
- `Compass`：罗盘导航
- `Skills`：技能图谱
- `Projects`：开源项目
- `Devices`：设备展示
- `Timeline`：时间线大事记
- `Albums`：摄影相册
- `Categories`：分类索引
- `Tags`：标签索引
- `About`：关于我

#### 写法 B：自定义外部链接
```yaml
links:
  - name: "GitHub 源码"
    url: "https://github.com/LyraVoid/Shirone"
    icon: "fa6-brands:github"
    external: true
```

#### 写法 C：下拉子菜单（多级分组）
使用 `children` 字段即可创建带有展开浮层的下拉菜单：
```yaml
links:
  - name: "关于我"
    icon: "material-symbols:info-outline-rounded"
    children:
      - preset: About
      - preset: Skills
      - preset: Projects
      - preset: Devices
      - preset: Timeline
```

## 二、侧边栏布局编排：`config/sidebar.yaml`

Shirone 提供了数据驱动的侧边栏布局系统，你可以在宽屏电脑上开启双侧栏，也可以自由调整各个组件的上下排列顺序。

### 完整示例与属性说明

```yaml
enable: true

# 侧栏编排模式：
# - "single"：单栏模式，所有组件放入同一个侧栏（适合紧凑排版）
# - "dual"：双栏模式，在宽屏电脑（屏幕宽度 >= 1280px）时自动展开左、中、右三列布局
arrangement: "dual"

# 主侧栏位置："left"（靠左，默认）| "right"（靠右）
side: "left"

# 侧边栏组件清单（按顺序自上而下摆放）
components:
  # 博主名片卡
  - type: "profile"
    enable: true
    slot: "top"         # "top" 表示固定在顶部

  # 侧栏音乐播放器
  - type: "music"
    enable: true
    slot: "top"

  # 首页公告栏（仅在首页展示）
  - type: "announcement"
    enable: true
    slot: "top"
    pages: ["home"]

  # 文章分类列表（粘性吸顶）
  - type: "categories"
    enable: true
    slot: "sticky"      # "sticky" 表示页面向下滚动时吸附在屏幕上方
    collapseAfter: 5    # 超出 5 个分类时显示“展开”按钮

  # 标签云
  - type: "tags"
    enable: true
    slot: "sticky"
    collapseAfter: 6

  # 站点统计（仅在 dual 双栏模式下放置在副侧栏）
  - type: "stats"
    enable: true
    slot: "top"
    column: "secondary" # "secondary" 表示放入副侧栏

  # 迷你日历
  - type: "calendar"
    enable: true
    slot: "top"
    column: "secondary"

  # 文章目录（仅在文章详情页展示并吸顶跟随）
  - type: "toc"
    enable: true
    slot: "sticky"
    column: "secondary"
    pages: ["post"]
```
