# 文章发布与排版指南

本篇文档介绍如何在内容仓库中编写与发布常规技术博客文章，以及使用主题专属的 Markdown 容器与行内排版扩展。

---

## 建立新文章

文章存放在内容仓库的 `content/posts/` 目录下，支持两种组织方式：

### 方式 A：单文件形式（最常用）
在 `content/posts/` 下直接新建 `.md` 或 `.mdx` 文件，例如：
`content/posts/my-first-post.md`

### 方式 B：文件夹目录形式（适合文章带有专属配图）
在 `content/posts/` 下新建一个独立文件夹，并在其中放入 `index.md` 和图片文件：
```text
content/posts/my-travel/
├── index.md
└── cover.webp
```

## 文章头部元数据规范

每篇文章的开头必须用三条横线 `---` 包裹一段元数据，用于定义文章标题、日期与分类：

```yaml
---
# 文章主标题（必填）
title: "我的第一篇博客文章"

# 发布日期（必填，格式如 YYYY-MM-DD）
published: 2026-08-27

# 最后更新日期（可选）
updated: 2026-08-28

# 文章摘要（可选，用于卡片简介与搜索引擎摘要，留空时自动截取正文前段）
description: "这是一篇关于现代前端技术架构与内容分离的实战总结。"

# 文章封面图（可选，支持绝对路径、相对路径或网络外链）
image: "https://example.com/cover.webp"

# 所属分类（可选，单分类）
category: "技术笔记"

# 标签列表（可选，可添加多个）
tags:
  - "Astro"
  - "前端"
  - "教程"

# 是否置顶显示在列表最前（默认为 false）
pinned: false

# 是否为草稿（设为 true 时在生产构建中自动隐藏）
draft: false

# 是否开启本篇文章的评论互动（默认为 true）
comment: true
---
```

## 文章加密保护功能

如果你有一篇私人日记或不想对公众完全公开的文章，可以使用内置的**文章加密功能**：

```yaml
---
title: "这是一篇加密的个人日记"
published: 2026-08-27
category: "生活"

# 开启加密
encrypted: true
# 设置访问密码
password: "your_secret_password"
# 密码提示文字（访客在输入密码界面可见）
passwordHint: "博主最喜欢的动漫人物名字是什么？"
---
```

设置后，构建期只会输出经过高强度加密的密文包，密码本身绝不会发送给浏览器。访客必须在页面弹窗中输入正确密码后，浏览器才会动态解密渲染正文。

## 常用排版与容器扩展全家桶

Shirone 内置了一整套符合 M3E 设计规范的 Markdown 扩展组件，构建期静态生成，无多余客户端 JS 开销。

### 1. 提示与警告容器 (Admonitions)
支持五种样式的容器组件，使用三冒号指令直接插入：

```markdown
:::note
这是一段普通的便签提示文字。
:::

:::tip
这是一个实用的技巧提示。
:::

:::important
这是一条关键的重要信息说明。
:::

:::warning
这是一条需要注意的警告提醒。
:::

:::caution
这是一条高风险操作的危险警告。
:::
```

同时也完全兼容标准 GitHub Alert 引用语法：
```markdown
> [!TIP]
> 这是一个基于引用语法的技巧提示。
```

---

### 2. 选项卡组容器 (Option Groups)
用于在同一块区域展示多种方案（如不同包管理器的安装命令、不同系统的配置方式）：

````markdown
:::option-group
=== npm
```bash
npm install shirone-theme
```
=== pnpm
```bash
pnpm add shirone-theme
```
=== yarn
```bash
yarn add shirone-theme
```
:::
````

---

### 3. 折叠面板容器 (Collapse Panels)
用于隐藏篇幅过长或可选阅读的补充内容，支持平滑折叠展开：

```markdown
:::collapse{title="点击查看详细配置说明" default-open=false}
这里是默认收起的详细排版和参数说明内容，支持嵌套任意 Markdown 元素。
:::
```

---

### 4. 步骤列表容器 (Steps)
用于展示有严格先后顺序的操作流程：

```markdown
:::steps
1. **初始化环境**
   安装 Node.js 22 及 pnpm 包管理器。

2. **同步内容**
   执行 `pnpm content:sync` 将内容物化到本地。

3. **启动预览**
   运行 `pnpm dev` 并在浏览器中查看站点效果。
:::
```

---

### 5. 交互式代码树 (Code Trees)
左侧展示多级文件树导航，右侧即时切换对应的代码面板。

#### 容器语法形式：
````markdown
:::code-tree{title="组件示例" height="360px" entry="src/Button.svelte"}
```svelte title="src/Button.svelte"
<script lang="ts">
  let { label = "Click" } = $props();
</script>
<button class="btn">{label}</button>
```

```css title="src/button.css"
.btn {
  background: var(--primary);
  color: var(--on-primary);
}
```
:::
````

#### 本地目录自动导入形式：
```markdown
@[code-tree title="工具函数库" entry="status.ts"](src/content/posts/my-post/snippets)
```

> **重要路径约定**：
> 在双仓库分离（`external` 模式）下，`@[code-tree]` 扫描基于**代码仓工作区根目录**。由于内容仓的目录必须物化后才能被代码仓读取，因此路径必须写物化后的相对路径（如 `src/content/posts/...` 或 `src/data/...`），而不能直接写内容仓自身的 `content/posts/...`。

---

### 6. 文件目录树 (File Trees)
用于展示项目目录结构，支持自动图标识别与高亮标记：

```markdown
:::file-tree{title="项目目录架构"}
- src/
  - components/
    - ++ Navigation.svelte # 新增组件
    - -- OldButton.astro # 废弃组件
  - content/
    - posts/
      - article.md
- astro.config.mjs
- package.json
:::
```

---

### 7. 行内增强语法（缩写词、批注与高亮）

- **缩写词浮窗提示 (Abbreviations)**：
  在文末定义缩写，正文中遇到对应词汇自动生成原生悬浮提示：
  ```markdown
  * [HTML]: 超文本标记语言（HyperText Markup Language）
  * [SSR]: 服务端渲染（Server-Side Rendering）

  现代 Web 开发推荐使用 HTML 和 SSR 架构。
  ```

- **行内批注 (Content Annotations)**：
  ```markdown
  这是正文内容^[这是一条紧随其后的行内批注说明文字]。
  ```

- **荧光高亮标记 (Marker Highlights)**：
  ```markdown
  这是一段使用了 ==荧光高亮视觉标记== 的重点文字。
  ```

### 8. GitHub 仓库动态卡片
使用 `::github` 行级指令，只需填入仓库路径即可自动拉取 Star、Fork、许可证和语言信息：

```markdown
::github{repo="LyraVoid/Shirone"}
```

---

### 9. 响应式图片画廊网格
使用 `:::grid` 容器指令可以创建多图画廊，支持自定义列数、宽高比和填充方式，并自带灯箱分组浏览：

```markdown
:::grid{columns=3 aspect="16/10" fit="cover"}
![春季风光](https://example.com/spring.webp)
![夏季海滩](https://example.com/summer.webp)
![秋日红叶](https://example.com/autumn.webp)
:::
```
